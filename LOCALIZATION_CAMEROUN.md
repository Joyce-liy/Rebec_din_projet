## 🌡️ Problèmes de Santé Courants

### 1. Paludisme (Très courant)
```
Symptômes: Fièvre, frissons, fatigue
Légende locale: "Fièvre typhoïde" (souvent erronée)
REBEC dit:
"Le paludisme est courant à Yaoundé. 
Les symptômes incluent fièvre sans raison.
CONSULTEZ UN MÉDECIN IMMÉDIATEMENT pour diagnostic.
Puis rendez-vous à une pharmacie avec l'ordonnance."
```

### 2. Diarrhées
```
Cause: Eau non purifiée, hygiène
REBEC dit:
"Les diarrhées sont courantes. 
Réhydratez-vous (eau + sel + sucre).
Si > 3 jours, consultez un médecin."
```

### 3. Infections Respiratoires
```
Cause: Pollution, changeant de saison
REBEC dit:
"La saison des pluies apporte des infections.
Consultez un médecin pour l'antibiotique adapté."
```

### 4. Problèmes d'Hypertension
```
Populaire chez: Adultes 40+
REBEC dit:
"L'hypertension est courante. 
Besoin d'ordonnance médicale ABSOLUE.
Pas d'auto-traitement!"
```
